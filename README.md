## 唯一当前任务

[#1 最小请求路径](https://github.com/Zhihui-Cui/concurrent-tcp-server/issues/1)：客户端发送有明确边界的请求，服务端执行 echo 或确定性计算并返回可核验结果。允许成熟库。

在Linux基础收尾后进行，不拖延10月中旬独立模型训练。

## 验收与预算

- 环境、依赖版本及真实运行命令。
- 正常请求、断开重连、超长/错误输入；明确消息边界。
- 原始TCP正确处理部分读写、EOF与错误；使用库时说明其负责的部分。
- 正常结束释放连接等资源，说明请求完整路径和未支持范围。

理解1–2h、实现3–4h、验证与说明2–4h；合计不超过10h的学习预算。若做不完，缩小范围、记录缺口，不虚报完成。
